## 💗 About Mochi Space 5D

**Mochi Space 5D** is a cute, customizable multi-window workspace designed to bring your favorite websites into one magical place.

Create your own virtual rooms, open multiple websites side by side, decorate every window with unique frames, and personalize your workspace with dreamy themes and interactive modes.

Whether you're studying, coding, researching, or simply enjoying your favorite websites, Mochi Space 5D lets you create a space that feels uniquely yours.

> ✨ One universe. Endless windows. Your own little world.

## 🚀 Getting Started

### Option 1: Run Locally

1. Download or clone this repository.
2. Locate `index.html`.
3. Open it in a modern web browser.
4. Create your first workspace.
5. Add a website URL and start customizing!

No dedicated backend is required for the basic local interface.

### Option 2: Host Online

You can host the static website using services such as:

- GitHub Pages
- Netlify
- Cloudflare Pages

Upload `index.html` and any separately required assets. If the project is implemented as a fully self-contained HTML file, no additional project files are needed.

## ⚠️ Important Notes

### Website Embedding

Not every website allows itself to be displayed inside an iframe.

Some websites restrict embedding through security policies such as `X-Frame-Options` or Content Security Policy.

When a website cannot be embedded, open it in a new browser tab instead.

### Performance

Opening many websites simultaneously can consume substantial memory and CPU resources. Actual performance depends on your device, browser, and the websites being loaded.

### Privacy

Workspace information stored locally remains subject to your browser's storage and privacy settings. Clearing browser data may remove saved workspaces.

Avoid storing passwords, authentication tokens, or other sensitive information in workspace configurations.
